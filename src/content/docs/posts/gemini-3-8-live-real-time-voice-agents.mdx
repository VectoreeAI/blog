Real-time voice agents are becoming a new way to interact with AI.

Instead of typing a request and waiting for a response, users can have a continuous conversation with an AI agent that understands speech, processes context, and takes actions through tools.

Google's Gemini 3.8 Live is designed for this type of experience. It brings native speech-to-speech interaction, support for 97+ languages, visual context, and tool calling to real-time AI applications.

For developers building voice agents, Gemini 3.8 Live provides a foundation for creating more interactive AI experiences.

## What Is Gemini 3.8 Live?

Gemini 3.8 Live is Google's real-time voice model for applications that need natural, continuous conversations.

It uses native speech-to-speech interaction through the Gemini Live API, allowing developers to build applications where users communicate with an AI agent directly through voice.

The model can also work with external tools and APIs while maintaining the conversation.

This makes Gemini 3.8 Live suitable for voice assistants, customer support agents, AI tutors, productivity tools, and other conversational AI applications.

Google provides access to Gemini 3.8 Live through the Gemini API and Google AI Studio.

## 97+ Languages for Voice Agents

One of the key capabilities of Gemini 3.8 Live is its multilingual support.

The model supports more than 97 languages, making it possible to build voice applications for users across different markets with the same underlying model.

For global AI products, multilingual voice support can simplify the development of voice experiences for different users and regions.

A voice agent can handle conversations across multiple languages while maintaining a consistent interaction model.

## Building Real-Time Voice Agents

Gemini 3.8 Live is not only designed for conversations. It can also become part of an AI agent that understands requests, processes information, and uses external tools to complete tasks.

For example, a customer support agent could receive a spoken request, retrieve information from a database, call an external API, and continue the conversation with the user.

A simple architecture could look like this:

User
↓
Voice Input
↓
Gemini 3.8 Live
↓
Reasoning and Tool Calls
↓
External APIs and Backend
↓
Agent Response

This turns the voice model into the conversational layer of a complete AI agent.

## Voice, Vision, and Tools

Gemini 3.8 Live also supports visual context.

A real-time interaction does not have to be limited to what the user says. Applications can provide visual information to the model as part of the interaction.

For example, a user could show an object, document, or interface while talking with the agent.

Tool calling adds another important capability.

Gemini 3.8 Live supports asynchronous function calling, allowing API or tool operations to run while the conversation continues.

This can be useful for agents that need to retrieve information or perform actions without stopping the entire voice interaction.

Together, voice, visual context, reasoning, and tools allow developers to build more capable real-time AI agents.

## Gemini 3.8 Live Extended Thinking

Google also introduced Gemini 3.8 Live Extended Thinking alongside Gemini 3.8 Live.

The two models are designed for different workflows.

Gemini 3.8 Live focuses on real-time voice interaction, while Gemini 3.8 Live Extended Thinking is designed for more complex reasoning and multi-step tasks.

For AI agents, developers can choose the model based on the task.

A real-time conversation may use Gemini 3.8 Live, while a more complex task may use a model with deeper reasoning capabilities.
