Vectoree is one project: models, tools, auth, database, and storage on a single key. The CLI is how you attach that project to the repo your agent already lives in.

This walkthrough gets you from an empty Cloud account to `whoami` and `ai chat "ping"` succeeding. After that, the same key powers app calls through the [Model Gateway](/posts/call-models-through-vectoree-gateway/).

<CtaRow />

## Create a Cloud account

Open [vectoree.ai](https://vectoree.ai), sign in with Google or email, and make sure you have an organization. Top up the org wallet in the dashboard before paid gateway or Tool Hub usage will succeed.

## Install the Skill

Agents need task-oriented context, not only an API. From the machine that runs Cursor, Claude Code, or Codex:

```bash
npx skills add VectoreeAI/vectoree-skills
```

The skill pack lives in [VectoreeAI/vectoree-skills](https://github.com/VectoreeAI/vectoree-skills).

## Login and link

![CLI setup is login in the browser, then link, which writes a scoped project key under .vectoree. You do not pass a project id on the command line.](/posts/vectoree-cli-project-key-workflow/01-login-link-key.svg)


From your app repo:

```bash
npx @vectoree/cli login
npx @vectoree/cli link
```

`login` opens a browser (PKCE). `link` asks you to pick or create a project, then writes a scoped API key under `.vectoree/`. You do not pass a project id on the command line.

Headless CI: `npx @vectoree/cli login --use-device-code`, or set `VECTOREE_API_KEY` and skip login.

Production API default is `https://vectoree.ai`. Staging: `VECTOREE_API_URL=https://vectoree.net`.

## Check the gateway

![Setup is done when whoami and ai chat ping succeed. That same key then reaches chat, tools, the database, and storage. App auth for end users is a different login.](/posts/vectoree-cli-project-key-workflow/02-same-key-check.svg)


Setup is done when chat works:

```bash
npx @vectoree/cli whoami
npx @vectoree/cli ai chat "ping"
```

If those already succeed, skip `login` / `link`. Do not probe every modality here — start with chat, then open other surfaces when you need them.

Optional: start from a Template in the dashboard instead of an empty folder. Copy the prompt, let the agent clone a Vectoree-adapted repo, then continue from the check above in that directory.

## Connect Tool Hub

Use a scoped project key with `tools:*` (from `link` or Dashboard → API Keys). The CLI can write MCP config for your editor:

```bash
npx @vectoree/cli tools status
npx @vectoree/cli tools snippet --write --replace-search
```

`--write` defaults to Cursor (`.cursor/mcp.json`). Pass `--client claude` or `--client vscode` for the others. `--replace-search` removes third-party search servers so the agent uses Vectoree instead.

REST probes:

```bash
npx @vectoree/cli tools search "<query>"
npx @vectoree/cli tools extract <url>
```

## Useful commands

```bash
npx @vectoree/cli db list
npx @vectoree/cli storage buckets list
npx @vectoree/cli tools status
npx @vectoree/cli --help
```

Every command accepts `--json`. Destructive commands confirm unless you pass `--yes`.

App Auth (`auth status` / `auth snippet`) configures login for your app's end users. That is not the same as logging into Vectoree Cloud.

Optional: point Codex CLI at the Model Gateway with the one-liner in the [CLI setup docs](https://docs.vectoree.ai/quickstart) — useful after the project key exists, not a substitute for `login` and `link`.
