Anthropic has introduced **Claude Fable 5.1** and **Claude Mythos 5.1**, its latest models for coding, knowledge work, research, and long-running agentic tasks.

The release marks another step in the evolution from AI assistants to **AI agents** that can plan, use tools, execute multi-step tasks, and work with less human supervision.

For developers building coding agents and AI-native applications, the new models highlight an important shift: AI is moving from simply generating responses to actively completing complex tasks.

## What Is Claude Fable 5.1?

Claude Fable 5.1 is Anthropic's latest generally available model for coding, knowledge work, and long-running problem-solving tasks.

The model supports a **1 million token context window** and up to **128K output tokens**, making it well suited for large codebases, complex research, and extended agent workflows.

Anthropic reports strong improvements over Fable 5 across coding and knowledge-work evaluations, including **Terminal-Bench-Science 0.1** and **Terminal-Bench 4.0**.

Fable 5.1 is designed for workloads such as:

- Complex software development
- Debugging and code review
- Working across large codebases
- Long-running coding tasks
- Research and knowledge work
- Tool-using AI agents
- Multi-step autonomous workflows

The model is also available through the Claude API as `claude-fable-5-1`.

## Claude Mythos 5.1 for Advanced Research

Claude Mythos 5.1 uses the **same underlying model as Fable 5.1**, but with a different level of safeguards.

While Fable 5.1 is generally available, Mythos 5.1 is available through Anthropic's trusted access programs, including applications focused on advanced cybersecurity and life sciences research.

This model strategy reflects an increasingly important aspect of frontier AI development: model capability and model access do not have to be identical.

Different workloads may require different levels of safeguards, access controls, and deployment environments.

## Why Fable 5.1 Matters for AI Agents

The most important part of the Fable 5.1 release is not simply another improvement in benchmark scores.

It is the continued shift from **AI assistants to AI agents**.

Traditional AI applications often follow a simple pattern:

> Prompt → Model → Response

Agentic applications are more complex:

> Goal → Reasoning → Tools → Execution → Feedback → Iteration → Result

An AI agent needs to understand a goal, break it into multiple steps, interact with external tools, maintain context, recover from failures, and continue working until the task is completed.

This makes model capabilities such as long-context reasoning, tool use, coding, and sustained execution increasingly important.

Fable 5.1 is designed around exactly these types of workloads.

## More Efficient Agentic Workloads

Performance is only one part of building useful AI agents.

For production applications, **cost and efficiency** matter just as much.

Anthropic has kept Fable 5.1 and Mythos 5.1 at the same base pricing as Fable 5, while reducing prompt cache read pricing to **$0.25 per million tokens**.

Because agentic applications often reuse large amounts of context across multiple steps, cheaper cache reads can make long-running workflows more economical.

This is particularly relevant for coding agents, research agents, and applications that repeatedly operate on the same codebase or context.
