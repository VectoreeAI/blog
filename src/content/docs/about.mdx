Vectoree Blog hosts long-form updates: product narrative, how-tos, comparisons,
and changelogs that benefit from SEO and a public git history.

## What belongs here

- Gateway / billing / CLI / Skill explainers
- Launch notes and comparison pieces
- Operator-facing runbooks written as articles

## What belongs in docs

API reference, SDK guides, and conceptual product docs stay on
[docs.vectoree.ai](https://docs.vectoree.ai) (Mintlify).

## URLs

| URL | Role |
| --- | --- |
| `https://blog.vectoree.ai` | Canonical blog |
| `https://vectoree.ai/blog` | 301 redirect to the canonical host |
